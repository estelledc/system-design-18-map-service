# Repository instructions

- This is an independent clean-room learning repository for one bounded map-service invariant.
- Keep source ingestion, dataset publication, tile/feature response, route computation, client receipt/render, navigation, arrival,
  and real-world safety as separate facts.
- Never add real credentials, people, device traces, addresses, routes, proprietary map data, copied third-party prose, diagrams,
  images, data, or code.
- Preserve unrelated work. Stage exact paths, keep commits single-purpose, and do not add co-author trailers unless requested.
- Infrastructure-dependent conclusions require the matching real service in public CI; mocks cannot prove cross-service behavior.
- A benchmark is a bounded synthetic observation for its exact fixture and runtime, never a production-capacity or routing-quality
  claim.
